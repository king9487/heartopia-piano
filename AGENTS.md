# Project Working Preferences

- After completing any requested file modification, run verification appropriate
  to the change and automatically create a focused Git commit without waiting for
  a separate commit request.
- Include only files belonging to the completed task. Preserve unrelated user
  changes and never commit credentials, generated output, logs, or temporary files.
- If verification fails because of a pre-existing or unrelated issue, report it
  clearly; commit the requested change only when its own relevant checks pass.
